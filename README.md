# Pinnacle Shield Insurance Website

A responsive multi-page website for a company called Pinnacle Shield Insurance built using HTML, CSS, Bootstrap, and JavaScript.

This project contains responsive web design, semantic HTML, custom CSS, dynamic JavaScript interactivity, quote calculations, form validation, quote comparison tool, saved quotes, and FAQ search functionality.

## Project Overview

Pinnacle Shield Insurance is an insurance provider website designed to help users:

- learn about the company
- explore insurance products
- calculate auto, home, and life insurance quotes
- compare multiple quotes
- save quotes locally
- print quote summaries
- browse frequently asked questions

The site is fully responsive and designed to work across:

- Mobile: 375px
- Tablet: 768px
- Desktop: 1024px

## Features

## Homepage

- Responsive navigation bar
- Hero section with call-to-action button
- “Why Choose Us” cards
- Insurance product types section
- Customer testimonials
- Shared footer with company/contact details

## Get a Quote Page

- Insurance type selection cards:
  - Auto Insurance
  - Home Insurance
  - Life Insurance
- Dynamic form sections that appear based on selected insurance type
- Shared customer info fields:
  - Full Name
  - Email Address
  - Age
  - ZIP Code
- Real-time Full Name validation
- Full client-side form validation with custom error messages
- Quote calculation for:
  - Auto Insurance
  - Home Insurance
  - Life Insurance
- Results section hidden by default and shown after calculation
- Quote summary card with:
  - Customer name
  - Insurance type
  - Monthly premium
  - Annual premium
- Breakdown table showing rating factors and impacts
- Action buttons:
  - Get Another Quote
  - Save Quote
  - Compare Quotes
  - Print Quote
- Saved Quotes section using `localStorage`
- Delete button for removing saved quotes
- Quote Comparison section showing:
  - First Quote summary card
  - Second Quote summary card
  - Two breakdown tables side by side
- Print-friendly quote output with custom print styling

## About Us Page

- Company overview section
- Executive team cards
- Company values section

## FAQ Page

- Accordion with common questions
- Live filtering/search
- Search bar
- Search matches both question and answer text
